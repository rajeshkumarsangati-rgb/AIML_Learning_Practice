# Project Overview

This repository contains a small data-engineering and analytics exercise with the following modules:

- `data_pipeline` — scrapes book metadata, cleans and normalizes it, loads it into SQLite, and saves the executed SQL results as CSV outputs.
- `analytics` — reads the SQLite database generated by the pipeline and calculates summary metrics and category-level insights.

For the exact run steps and database/query details, see the data pipeline documentation in [data_pipeline/README .md](data_pipeline/README%20.md).

To run the analytics layer from the project root:

```bash
python analytics/src/analytics.py
```
